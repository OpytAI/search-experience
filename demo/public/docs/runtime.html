Runtime notes

How the AgentOS search machine boots: kernel and search-atlas built from source, and the thin host that only does tools and serviceCall.

What loads

  • kernel.wasm — guest VM from the AgentOS build graph.
  • search-atlas.tar — base + /svc/sqlite + /svc/searchd.
  • mc-core.mjs — browser runtime to create/restore the machine.
  • Host tools — same-origin fetch, HTML extract, Mixedbread embed.

Authority boundary

Crawl plan, journals, FTS5/VANN, fusion, and generation promotion live in /svc/searchd. The host never ranks pages itself; it only performs bounded effects and talks the searchd JSON protocol.

Dual databases Queries always read /var/searchd/index.db. Refreshes rebuild candidate.db, then promote when the candidate is valid.

Keyboard

Press ⌘K / Ctrl K on this page to open site search — the same shortcut works on home and blog pages.
