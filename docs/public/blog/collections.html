Collections example

Docs and blog stay independent sections in the palette — separate labels, prefixes, and crawl seeds — without the host inventing ranking policy.

Why collections

Integrators configure crawl scopes (seeds, path prefixes, limits). The guest owns how those scopes become indexed generations. The UI only presents collection labels and routes selection to the right result set.

On this site

  • Documentation — seeds under /docs/, prefix docs:.
  • Blog — seeds under /blog/, prefix blog:.
  • Empty query can show recents; typed queries fan out per collection.
Try a prefix Open search with ⌘K, type blog: and a word from this page to stay inside the blog collection.

Presentation

Each hit can carry a preview (eyebrow, title, description, facts). The palette keeps list and preview side-by-side on desktop so scanning feels like a command bar, not a bare results table.
