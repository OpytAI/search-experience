Why Mixedbread ships in the package

Hermetic embeddings keep search offline-capable and CSP-simple—at the cost of package size.

Model

The release pins Mixedbread mxbai-embed-xsmall-v1 UINT8 ONNX plus tokenizer files (Apache-2.0). Runtime is ORT Wasm shipped under model/runtime/ (MIT).

Why not a CDN

Remote model fetch would add third-party origins, version skew, and failure modes on locked-down networks. Same-origin package bytes match the “static folder” install story.

Fingerprint

Model identity participates in snapshot compatibility. Swapping weights without a coordinated fingerprint story would desynchronize vectors and warm restores—hence no supported “drop in any ONNX” escape hatch today.
