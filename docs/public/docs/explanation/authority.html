Who owns ranking and crawl policy

Split-brain ranking is the failure mode this architecture exists to prevent.

Guest /svc/searchd

Owns crawl plan and queues, schema application, FTS and VANN writes, fusion parameters, generation metadata, promote, and status claims (including when semantic is honestly ready).

Host tools

Own side effects the guest must not perform with ambient browser authority unbounded: HTTP GET with allowlists, HTML parse, embedding inference. They return data; they do not decide result order for production queries.

UI

Owns presentation, prefixes as query UX, recents, and selection events. TypeScript FTS/RRF modules under src/oracles are test oracles for parity—not a second production ranker.

Worker

Owns boot/restore, tool wiring, serviceCall queueing, multi-tab indexing lock, diagnostics. It is orchestration, not relevance.
