Debug empty or wrong results

Work through network, CSP, seeds, and storage when search misbehaves.

Nothing opens

  • Manifest / entry script 404 → wrong unpack path or assetBase.
  • .mjs as application/octet-stream → fix MIME.
  • CSP violations → CSP guide.
  • autoMount: false without an element → bootstrap error.

Opens but zero hits

  • Wait for ready; first crawl is asynchronous.
  • Confirm seeds resolve (Network shows same-origin GETs).
  • Query shorter than minQueryLength.
  • Prefix mode stuck on a collection with no matches—clear the prefix.

Wrong pages indexed

Guest follows same-origin links from seeds. Tighten seeds and internal links; do not rely on include prefixes alone yet.

Stale package after deploy

Hard refresh; clear Cache Storage; unregister old service workers under the package scope. Replace the entire agentos-search/ tree on upgrade.

Private host errors

Fetch blocks private/link-local hosts unless that origin is the page origin allowlist entry (local demos). Production should use public hostnames.
