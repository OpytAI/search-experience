Place the launcher yourself

Disable auto-mount and put <mc-site-search> where your design system expects the control.

Markup

<header class="app-bar">
  <mc-site-search placeholder="Search docs"></mc-site-search>
</header>
<script>
  globalThis.AgentOSSearch = { autoMount: false, showLauncher: true };
</script>
<script type="module" src="/agentos-search/agentos-search.mjs"></script>

Rules

  • Config must run before the module script.
  • If autoMount is false and no element exists, bootstrap fails—by design.
  • showLauncher: false hides the button when you only want ⌘K (desktop) or a custom open control calling into the element API later.

Styling the host

The custom element is the theming root. See theme how-to and CSS tokens.
