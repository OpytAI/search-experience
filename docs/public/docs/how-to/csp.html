Set Content-Security-Policy for the package

Allow modules, module workers, Wasm compile, blob imports, and same-origin connect—without opening a third-party script CDN.

Minimum directives

Content-Security-Policy:
  script-src 'self' 'wasm-unsafe-eval' blob:;
  worker-src 'self' blob:;
  connect-src 'self';

Why each token

  • 'self' — page module, worker scripts, package assets, crawl GETs on the page origin.
  • 'wasm-unsafe-eval' — kernel and ONNX Runtime compile under CSP (prefer over broad 'unsafe-eval').
  • blob: — verified package JS re-imported from blob URLs after SHA-256 checks (mc-core, embedder).

What you do not need

  • Third-party model or script hosts (weights ship in the package).
  • Cross-Origin Isolation / COOP-COEP for SharedArrayBuffer (ORT runs single-thread here).

Symptoms of a bad CSP

Console: blocked Wasm, failed dynamic import, worker construction errors. Fix the directive that the violation names; do not disable CSP site-wide as the first move.
