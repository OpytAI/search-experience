Security surface

Hard limits on network, storage side effects, and navigation from search results.

Fetch

  • http(s) only; credentials: "omit"
  • Allowlist: page origin (visitor product)
  • Private/link-local hosts blocked unless that origin is explicitly the page origin
  • Redirect final URL must remain allowed
  • Fixed UA AgentOSSearch/1.0
  • Body and timeout caps

Extract / index text

Skips script, style, template, svg, canvas, form, dialog, nav, footer, header regions when building blocks. Links retained only if sanitizable to http(s).

Result navigation

Hits mapped through sanitizeHttpUrl / same-origin filters before palette navigation.

SQL

Guest builds FTS MATCH and dynamic SQL through quoting helpers (sql_safe); treat untrusted query text as hostile input still—defense is layered, not “stringly SQL forever.”
