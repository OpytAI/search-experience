Intercept selection in an SPA

Default selection assigns location to the hit URL. You will cancel that and route inside a client-side app instead.

Default behavior

On select, the element dispatches cancelable mc-search-select, then if not canceled navigates with location.assign to a sanitized same-origin http(s) URL.

1. Listen on document or the element

document.addEventListener("mc-search-select", (event) => {
  const { item, method } = event.detail;
  event.preventDefault();
  // your router
  history.pushState({}, "", item.href);
  // render route for item.href
});

2. Trust only sanitized hrefs

Hits already pass through host sanitization (http/https, same-origin when origin is known). Still treat item.href as untrusted input for your router: only open paths you allow.

3. Preserve query optional

Attribute preserve-query keeps the input when the dialog closes—useful if your shell reopens search often. Default clears query and mode on close.
