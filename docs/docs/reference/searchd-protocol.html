searchd protocol

Guest authority speaks JSON over vm.serviceCall("searchd", requestBytes). Source of truth: guest/searchd/searchd.protocol.json and src/protocol/searchd.ts.

Transport

Mode serviceCall only. Paths: active index /var/searchd/index.db, candidate /var/searchd/candidate.db, state /var/searchd/state.json.

Ops

opRole
configureCollections, schema SQL, model fingerprint, compatibility key, page origin, optional resume
statusReady / phase / counts / semantic claim
crawl_stepQueue work; host fetch+extract; writes active or candidate
embed_stepBatch embed via host; VANN insert
queryAlways reads active index; FTS + optional vector + RRF
refreshStart candidate generation
checkpointPersistence markers (lexical | semantic | idle)
promoteCandidate → active when valid
cancelCancel in-flight work

Response envelope

Ok: { v, id, ok: true, op, status?, progress?, hits? }. Err: { v, id, ok: false, code, error }.
