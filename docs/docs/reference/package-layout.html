Unpacked agentos-search/ tree shipped by //:release.

agentos-search/
├── agentos-search.mjs
├── agentos-search.manifest.json
├── agentos-search-runtime.mjs
├── agentos-search-sw.mjs
├── agentos-search-embed.mjs
├── kernel.wasm
├── search-atlas.tar
├── mc-core.mjs
├── catalog-compiler.wasm
├── index/schema.sql
├── searchd/searchd.protocol.json
└── model/
    ├── model.onnx
    ├── tokenizer.json
    ├── tokenizer_config.json
    ├── config.json
    └── runtime/          # ORT jsep .mjs + .wasm

Manifest lists digests for integrity. Optional prewarm adds snapshot assets. Transport in manifest must be serviceCall.
