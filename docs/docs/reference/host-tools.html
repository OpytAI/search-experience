Host tools

Effects the guest may call. Addresses are four-segment AgentOS tool ids.

AddressInput (summary)Behavior
host.org.main.search.fetchurl, maxBytes?, timeoutMs?GET, credentials omit, fixed UA AgentOSSearch/1.0, origin allowlist, private host rules, redirect final origin check
host.org.main.search.extracturl, htmlTitle (H1 preferred), description, blocks, same-document links; skips script/style/nav/…
host.org.main.search.embed.batchtexts[], kind?Mixedbread UINT8 batch via hermetic embedder + ORT

Guest-supplied User-Agent on fetch is ignored on the visitor path. Defaults: maxBytes capped (order 2–8 MiB), timeout capped (order 0.5–60s).
