Reference

/docs/reference/schema.html

Index schema

SQLite schema applied by searchd (index/schema.sql). Lexical and vector indexes share chunk rowids for fusion joins.

Core tables

  • collections — id, label, counts, built_at
  • pages — stable_id, collection_id, url, canonical_url, title, description, content_hash, indexed_at
  • chunks — page-scoped body units with title/heading/body, ordinal, metadata_json
  • search_meta — key/value generation metadata

FTS5

chunks_fts is external-content FTS5 over title, heading, body with collection_id UNINDEXED, unicode61 tokenizer, diacritics stripped. Triggers keep FTS aligned with chunks.

VANN

chunk_vec: float[384] cosine embeddings, partitioned by collection_id, rowid aligned with chunks for exact fusion joins. HNSW-style params (M, ef_construction, ef_search) set in schema.

Dual files

Active queries use /var/searchd/index.db. Refresh builds candidate.db then promote swaps generations when pages and chunks are non-empty.
