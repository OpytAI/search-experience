Theme the palette

Align colors, radius, and width with your product chrome using CSS variables on mc-site-search.

Quick theme

mc-site-search {
  --mc-search-fg: #0f172a;
  --mc-search-surface: #ffffff;
  --mc-search-focus: #4f46e5;
  --mc-search-border: #e2e8f0;
  --mc-search-width: 720px;
  --mc-search-radius: 12px;
}

Palette vs sheet

Desktop uses a centered dialog (layout="palette"). At max-width 680px the host sets layout="sheet": full viewport, safe areas, close control. Tokens like --mc-search-width and --mc-search-top apply to palette mode; sheet uses visualViewport-driven height.

Dark mode

The element ships prefers-color-scheme: dark defaults. Override the same variables inside your own dark scope if the page theme is class-based rather than system preference.
