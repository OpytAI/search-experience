How-to

/docs/how-to/upgrade.html

Upgrade the package safely

Ship a new compatibility unit and accept intentional cold boots when digests change.

Replace the whole directory

Copy a fresh unpack of release.tar over agentos-search/. Do not cherry-pick kernel.wasm or search-atlas.tar from another build.

Expect snapshot invalidation

Compatibility keys include kernel, image, schema, model fingerprint, searchd protocol, collections, and page origin. Visitors with old OPFS snapshots cold-boot—by design.

Re-prewarm if you use warm snapshots

Old gzip MCSN will not match new digests. Capture again against the new package and re-run package-prewarm.

Config

Integrator AgentOSSearch config is yours; review collection seeds when IA changes. Protocol bumps are rare and coordinated via versions reference.
