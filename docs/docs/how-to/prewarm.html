Prewarm a gzip MCSN snapshot

Capture after a real crawl; inject snapshot assets and digests into a release directory.

Capture

bun tools/browser-e2e.mjs \
  --release-dir=docs/public/agentos-search \
  --export-snapshot --out=./warm

bun src/publisher/cli.ts --capture \
  --release-dir=docs/public/agentos-search --out=./warm

Publisher also supports --origin=… plan-only mode without a guest for CI scaffolding.

Inject

bun tools/package-prewarm.mjs \
  --release-dir=path/to/agentos-search \
  --snapshot=./warm/search.snapshot \
  --metadata=./warm/search.snapshot.metadata.json

Format rules

  • Gzip only (meta.encoding: "gzip").
  • snapshotSha256 is over gzip bytes.
  • Raw MCSN on disk is rejected at restore.
