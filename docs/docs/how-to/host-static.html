Host the package on a static origin

Serve agentos-search/ as same-origin static files with correct types and no truncated binaries.

Unpack location

Default URL space is /agentos-search/*. Unpack into the directory that maps to your site root. If you nest under /assets/search/, set assetBase and script src together.

Required MIME behavior

ExtensionContent-Type
.mjstext/javascript or application/javascript
.wasmapplication/wasm
.jsonapplication/json
.tar / .onnxoctet-stream or vendor type; full body, not HTML error pages

nginx often needs an explicit types map for mjs and wasm. CDNs usually already do.

Body size limits

search-atlas.tar, model.onnx, and Wasm files are multi-megabyte. Ensure proxies do not 413 or truncate. Guest cold boot reads the image as bytes.

Service worker

Registration is best-effort under the package path for distribution caching only. Failure is non-fatal; search still runs online.
