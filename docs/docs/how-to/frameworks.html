Wire Next.js, Vite, Nuxt, and static hosts

Unpack into each stack’s static directory and load a real browser module—not a server-only import.

Vite / Nuxt / Astro / plain static

tar -xf release.tar -C public
# index.html or layout:
<script type="module" src="/agentos-search/agentos-search.mjs"></script>

Next.js App Router

Load once from the root layout with next/script or a normal module script. Config in beforeInteractive if needed; module in afterInteractive:

import Script from "next/script";
// in RootLayout body:
<Script id="aos-cfg" strategy="beforeInteractive">
  {`globalThis.AgentOSSearch = globalThis.AgentOSSearch || {};`}
</Script>
<Script type="module" src="/agentos-search/agentos-search.mjs" strategy="afterInteractive" />

Avoid self-closing tags that never execute in the browser. Unpack into public/.

Hugo / SvelteKit

Unpack into static/ (or Hugo’s static dir). Add the module script to the base template.

This monorepo’s docs site

bazel run //docs:dev
# builds //:release when needed and stages docs/public/agentos-search/
