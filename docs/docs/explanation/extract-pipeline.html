From HTML to hits

How raw markup becomes titles, bodies, and palette rows people can scan.

Extract

Host extract removes noisy tags, finds main/article/body, walks headings and block tags into blocks, collects sanitizable links, reads meta description and canonical, and chooses title = H1 || document title || path fallback.

Index body ordering

Guest indexing prefers description and longer blocks first, then short blocks—so FTS still sees eyebrow tokens, but snippets and secondaries are not dominated by “Product demo” style labels.

Hit mapping

hitsToItems filters non-http(s) and optional off-origin URLs, sets label from title, secondary from heading/snippet/path, and builds preview facts. That mapping is presentation—not a second ranker.
