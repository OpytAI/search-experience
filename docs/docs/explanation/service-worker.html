Why there is no distribution service worker

A worker scoped under the package directory would not control the host page, so it would not cache what matters and could interfere with other caches on the origin.

Current design

The product ships only a module worker for AgentOS, crawl coordination, and embeddings. Static package files rely on ordinary HTTP caching and CDN headers. There is no Cache Storage lifecycle.

If you add caching later

Use an owned cache-name prefix, a scope that actually controls clients you care about, and never delete unrelated caches on the origin. Until a measured need exists, omit the worker.
