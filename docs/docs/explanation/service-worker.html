What the service worker is for

Distribution caching only—not crawl, not ONNX, not AgentOS compute.

Scope

The worker script registers under the package directory with type: "module". It caches verified package assets by digest so repeat visits do not re-download multi‑megabyte Wasm and models unnecessarily.

Non-goals

It must not become a second indexer, a background crawl daemon with different policy, or a place to hide ranking. Registration failure is non-fatal so strict browsers or user settings cannot brick search.
