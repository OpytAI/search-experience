Hybrid ranking

Lexical FTS5 and semantic VANN are fused with reciprocal rank fusion inside the guest.

Lexical

Queries use FTS5 MATCH (prefix tokens via safe query builders). Fallback LIKE paths exist when FTS returns empty in degraded situations. Snippets prefer page description when present, else a body prefix ordered so short “eyebrow” lines are not first.

Semantic

Documents embed as Mixedbread-formatted text (title, heading, body). Vectors are 384-d cosine in VANN, partitioned by collection. Query embed goes through the same host tool when the guest does not receive a precomputed vector.

Fusion

RRF combines ranked lists with configurable k, candidate limits, and per-page diversity caps before the final limit. Hits expose match mode and optional lexical/semantic ranks for UI honesty.

Progressive UI

The worker may publish lexical results before hybrid refinement completes. The palette keeps selection stable by collectionId+id across reorderings.
