Warm snapshots

Full guest memory captures (MCSN) can seed OPFS when compatibility keys still match.

What is captured

Full MCSN of the running search machine after crawl/index work—not an ad-hoc SQLite file copy from outside the VM. Persistence goes through content store APIs; export tools gunzip/gzip at the codec boundary.

Gzip only

On disk and in packages, payload is gzip. Digests cover compressed bytes. Raw MCSN is rejected so there is one format to reason about.

Invalidation

Keys include kernel, image, schema, model fingerprint, protocol, collections hash, page origin. Change the product or the site config → cold boot. That is preferable to silently ranking with a mismatched model or schema.
