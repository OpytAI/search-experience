Command palette on the desktop, sheet on the phone

Search UI is a command surface. The same custom element becomes immersive when the keyboard is virtual and the viewport is short.

Desktop grammar

Type, move, confirm—shared with app launchers. Preview exists because scanning titles alone is hostile on dense sites. Keyboard chrome stays when a fine pointer is primary.

Phone grammar

Floating cards waste space and fight the software keyboard. Sheet mode claims the viewport, docks the field, sizes to visualViewport, and shows a close control when Esc chips disappear.

One implementation

Layout is a mode on mc-site-search, not a second mobile product. That keeps accessibility (modal dialog) and theming (one token set) coherent.
